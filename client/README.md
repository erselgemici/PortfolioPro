# PortfolioPro - Client (Angular 20)

```bash
npm install
npm start        # http://localhost:4200 (API'nin http://localhost:5080'de çalışıyor olması gerekir)
npm run build    # production build -> dist/client/browser
```

`/api` ve `/uploads` istekleri geliştirme sırasında `proxy.conf.json` ile API'ye yönlendiriliyor.
Kurulumun tamamı için ana klasördeki README'ye bak.
